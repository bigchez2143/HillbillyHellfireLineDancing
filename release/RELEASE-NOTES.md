# Line Dance Creator — notes for this zip

Hillbilly Hellfire Line Dance Creator is a free Windows application for writing, rehearsing, and teaching line dances.

## Download and run

Unzip the folder. There is no Setup installer and no desktop icon.

Double-click **Launch Line Dance Creator.bat**. **run.bat** in the same folder starts that launcher. The dance page opens at `http://127.0.0.1:8766/dance`.

No account is required.

Optional connections are zero-cost in this app. Bring your own credentials. The app does not include a shared AI key or paid credits. Writing, practice, the starter dance, and Publish work with no key.

## In the folder

- **Instructor one-pager.pdf** — one-page class guide. It does not ask for an account or a key.
- **sample/the-corn-maze-dance** — readable copy of The Corn Maze Dance. No song file is included. The app also adds this starter when My Dances is empty.
- **LICENSE** — freeware terms. Paid dance classes and your own choreography are allowed. Selling the Software is not. Your outputs stay yours. Third-party components and songs keep their own terms. The Software is provided as is. This is not an OSI open source license.
