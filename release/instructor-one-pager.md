# A short guide for class

Freeware from Hillbilly Hellfire. Open the app, start a dance, add moves, rehearse, export a sheet, then use Publish. You do not need an account or a key. Leave Workspace view on Basic.

## 1. Open the app

If this guide is next to **Launch Line Dance Creator**, double-click that. If you are in the project folder, double-click **app\run.bat**. The dance page opens in your browser. You can read this guide with no internet.

## 2. Start a dance

On **My Dances**, **The Corn Maze Dance** is already there, marked as a starter sample. No song file comes with it. Choose **Open dance** to look through the steps.

To begin your own dance, choose **Start without music**, type a dance name, and choose **Create dance**. You land on **Create / Edit**. **Start with music** is there when you already have a song file.

## 3. Add moves

On **Create / Edit**, under **Moves**, choose a row marked with a plus. The move goes into the sequence for the current part. A row marked **Preview** only shows the steps. It does not add the move. Choose **Save** and wait until the top bar says **Saved locally**.

## 4. Rehearse

Open **Practice**. Set **Count-in** to **None** if you want the count to start right away. Choose **Play**. The button changes to **Pause**, and the big count moves. Choose **Pause** to hold it. With no local audio file, rehearsal uses the metronome.

On **Music**, the **Song card** can hold a Spotify link. The link is for sharing and opening the song. It does not play with the dance. **Local audio file** is optional. If you add one, Practice plays that file.

## 5. Export a printout

Open **Export**. Fill in **Dance title**, **Choreographer**, and **Dance level** if you want them on the sheet. Choose **PDF sheet** for a printout you can hand to class.

## 6. Publish

Choose **Publish** in the top bar. **My Dances** has **Publish** on each dance too. Wait until the window says the step sheet and portable draft are in a folder on this computer. The step sheet is the printout. The portable draft is a copy you can open in this app on another computer. Nothing was sent to a website.

Choose **BootStepper**, **CopperKnob**, or **LineDance.com**. The site opens, and you upload the step sheet yourself. **Copy folder** copies the folder path. **Show folder** opens the folder. This screen does not ask for a key.

## Community links

Open **Line Dance Tools**. Under **Community** you will see BootStepper, CopperKnob, LineDance.com, and Hillbilly Hellfire. Add a class or studio site if you want. **Restore starter links** puts the original list back. These are links you open yourself. Hillbilly Hellfire is at hillbillyhellfire.com.
