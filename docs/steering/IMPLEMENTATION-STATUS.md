## Data and release boundaries

Development and browser tests used isolated directories. Original projects, songs, personal settings, historical references and user media must be preserved by the targeted installation manifest and private backup. The original reference PDF is not deleted or shipped. Common moves have not been removed. The new common-move explanations are explicitly review drafts; the existing catalog mechanics are not silently rewritten.

AI remains optional and user-supplied. No shared paid key, owner-funded inference, hosted account, model weight or background AI request was added. Provider and model setup are separate user actions. External resource links and the Hillbilly Hellfire website/YouTube footer do not embed tracking or advertisements into dance sheets.

The GitHub destination is the owner's existing HillbillyHellfireLineDancing repository. No private working folder or unreviewed historical Git tree should be pushed. The final public source/license/content gates are still open; no release publication is claimed.
